# Symfony UX Disclose

Symfony UX Disclose renders protected or sensitive values behind a button.
The real value is never part of the initial HTML: it lives on the server until
an explicit click triggers a server-side, rate-limited, audited disclosure.
It is part of [the Symfony UX initiative](https://ux.symfony.com/).

**This repository is a READ-ONLY sub-tree split**. See
https://github.com/symfony/ux to create issues or submit pull requests.
