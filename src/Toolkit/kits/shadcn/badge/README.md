# Badge

Displays a badge or a component that looks like a badge.

::: example Demo {"height": "150px"}

## Usage

## Examples

### Variants

Use the `variant` prop to change the variant of the badge.

::: example Variants {"height": "150px"}

### With Icon

You can render an icon inside the badge. Use `data-icon="inline-start"` to render the icon on the left and `data-icon="inline-end"` to render the icon on the right.

::: example With Icon {"height": "150px"}

### With Spinner

You can render a spinner inside the badge. Remember to add the `data-icon="inline-start"` or `data-icon="inline-end"` attribute to the spinner.

::: example With Spinner {"height": "150px"}

### Link

Use the `as` prop to render a link as a badge.

::: example Link {"height": "150px"}

### Custom Colors

You can customize the colors of a badge by adding custom classes such as `bg-green-50 dark:bg-green-800` to the `Badge` component.

::: example Custom Colors {"height": "150px"}

### RTL

To enable RTL support, set the `dir="rtl"` attribute on the root element.

::: example RTL
