# Accordion

A vertically stacked set of interactive headings that each reveal a section of content.

::: example Demo {"height": "300px"}

::: installation

## Usage

::: example Usage

## Examples

### Basic

A basic accordion that shows one item at a time. The first item is open by default.

::: example Basic {"height": "300px"}

### Multiple

Use the `multiple` prop to allow multiple items to be open at the same time.

::: example Multiple {"height": "400px"}

### Disabled

Use the `disabled` prop on `Accordion:Item` to disable individual items.

::: example Disabled {"height": "300px"}

### Borders

Add `border` to the `Accordion` and `border-b last:border-b-0` to the `Accordion:Item` to add borders to the items.

::: example Borders {"height": "300px"}

### Card

Wrap the `Accordion` in a `Card` component.

::: example Card {"height": "450px"}

### RTL

To enable RTL support, set the `dir="rtl"` attribute on the root element.

::: example RTL {"height": "450px"}
