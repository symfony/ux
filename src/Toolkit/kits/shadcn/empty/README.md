# Empty

Use the Empty component to display an empty state.

::: example Demo {"height": "300px"}

## Installation

::: installation

## Usage

::: example Usage

## Examples

### Outline

Use the `border` utility class to create an outline empty state.

::: example Outline {"height": "300px"}

### Background

Use the `bg-*` utilities to add a background to the empty state.

::: example Background {"height": "300px"}

### Avatar

Use the `Empty:Media` component to display an avatar in the empty state.

::: example Avatar {"height": "300px"}

### Avatar Group

Use the `Empty:Media` component to display an avatar group in the empty state.

::: example Avatar Group {"height": "300px"}

### InputGroup

You can add an `InputGroup` component to the `Empty:Content` component.

::: example InputGroup {"height": "300px"}

### RTL

To enable RTL support, set the `dir="rtl"` attribute on the root element.

::: example RTL {"height": "600px"}
