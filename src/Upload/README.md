# Symfony UX Upload

**EXPERIMENTAL** This bundle is currently experimental and is likely to change,
possibly significantly, before its first stable release.

Symfony UX Upload turns a Symfony file field into a complete upload field, with
direct and resumable transfers, whose value survives form validation and
re-rendering.

**This repository is a READ-ONLY sub-tree split**. See
https://github.com/symfony/ux to create issues or submit pull requests.
