# Symfony UX Editor

Symfony UX Editor provides a single Symfony form field on top of multiple
content-authoring editors (WYSIWYG, block and page-builder), with editor
implementations shipped as separate bridge packages.

**This repository is a READ-ONLY sub-tree split**. See
https://github.com/symfony/ux to create issues or submit pull requests.
