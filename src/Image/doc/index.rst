Symfony UX Image
================

Symfony UX Image processes uploaded raster images into versioned ``ImageAsset``
values, stores originals and responsive variants, and renders optimized
``<picture>`` markup.

The documentation is organized as a navigable, task-oriented corpus instead of
one monolithic page:

* `Installation and quick start <installation.md>`_
* `Profiles and processing <processing.md>`_
* `Responsive rendering <rendering.md>`_
* `Storage, Flysystem and CDN delivery <storage.md>`_
* `Doctrine and the ImageAsset contract <image-asset.md>`_
* `Regeneration and asynchronous processing <regeneration.md>`_
* `Integrations and customization <integrations.md>`_
* `Testing <testing.md>`_
* `Debugging <debugging.md>`_
* `Security and production budgets <security.md>`_
* `Complete configuration reference <configuration.md>`_

The `documentation landing page <overview.md>`_ explains the recommended
reading path and the boundaries owned by the bundle.
