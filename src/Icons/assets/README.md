# @symfony/ux-icons

JavaScript companion of [Symfony UX Icons](https://symfony.com/bundles/ux-icons/current/index.html):
render the icons dumped by the `ux:icons:dump` command in vanilla JavaScript, React or Vue,
with the same attributes and configuration as the `ux_icon()` Twig function.

**This repository is a READ-ONLY sub-tree split**. See
https://github.com/symfony/ux to create issues or submit pull requests.
